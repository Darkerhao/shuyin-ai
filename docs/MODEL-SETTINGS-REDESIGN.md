# 模型设置视觉与交互改版

日期：2026-11-02。首个落地模块为 `/settings/models`。

2026-11-04：模型页已随[工作台优化](UI-UX-REFINEMENT-PLAN.md)采用新的暖灰底、无外框白色内容面、40px输入与24px字段间距，移除旧控件材质覆盖。下文保留原改版的历史依据与验收，当前共享视觉以[本轮验收](UI-UX-REFINEMENT-VERIFICATION.md)为准。

## 设计方向

采用清爽、安静的创作工具风格。沿用书引墨绿品牌；通过清晰的模型列表、分组表单和固定操作区域改善设置体验。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 工作区 | `#f5f6f4` | 延用应用背景 |
| 内容面 | `#ffffff` | 模型库与配置表单 |
| 正文 | `#202d28` | 标题与主要信息 |
| 次级文字 | `#56635b` | 提示与说明 |
| 品牌色 | `#285b46` | 保存、默认、选中状态 |
| 选中面 | `#edf5f0` | 当前模型行 |

输入与未勾选复选框边界使用 `#81978a`，对白色背景对比度约3.12:1。

界面使用本机 Segoe UI、苹方、微软雅黑，不加载网络字体。字号层级为页面标题28px、配置标题17px、区块标题14px、字段13px、辅助说明12px。主要输入42px高，主要圆角8–14px，使用一致的8px间距节奏。文本与图片图标颜色仅辅助区分，始终同时显示用途文字。

布局全部左对齐：

960px以上模型库跟随页面，详情面板按可用视口限制高度，字段区独立滚动、操作栏固定在面板底部且不遮挡字段；960px以下纵向排列，配置随文档滚动，模型库独立滚动；600px以下表单单列、操作按钮换行。遵循应用已有的减少动态效果规则。

本页是设置工具，设计检索中的营销首页结构、推荐在线字体与金色配色不适用于当前任务；采用简洁栅格和清晰层级，同时保留书引现有品牌。避免将配置页拆成相同的统计卡片、加入装饰性渐变或持续动画。

## 交互约定

- 模型按文本、图片分组；名称、实际模型 ID、默认状态和凭据状态可以直接浏览。「密钥已保存」不代表已测试连接。
- 搜索只过滤列表，支持名称与模型 ID、忽略大小写；不切换当前模型，不丢未保存输入。提供清空、Escape和无匹配提示。
- 新增模型自动聚焦服务名称。切换模型、离开页面、撤销修改沿用应用内确认，取消保留输入。
- 密钥只允许显示用户本次输入的内容，已有密钥不回显；切换、撤销、保存成功时清空输入并恢复隐藏。失败保留输入以便修正。
- 保存为唯一主要操作；测试仅面向已保存且未修改的文本模型，禁用时在附近解释原因；图片模型明确引导在封面工坊生成背景验证。
- 推理强度放在「使用偏好」，保留全部既有档位；停用模型会同时取消默认，默认控制在停用时禁用。
- 读取失败提供重试入口，读取成功前禁用配置控件。删除独立于保存操作，沿用确认、Escape、焦点返回与处理中保护。
- 详情只维护一份当前表单，模型分组和默认摘要从已有列表派生。页面样式归属本模块，移除被替代的共享CSS，不新增依赖或另一套基础控件。

## 验收标准

1. 正常、空列表、搜索无结果、未保存、读取失败与处理中状态可理解、可操作。
2. 新增、编辑、保存、测试、停用、默认、删除和未保存保护继续成立；搜索、显隐与撤销按上述约定工作。
3. 1440、1120、800和360px无横向溢出；标签、键盘焦点、下拉浮层和确认弹窗正常。
4. 模型用途、推理参数、凭据安全和失败保稿行为保持一致。
5. lint、TypeScript、相关前端测试与生产构建通过。
