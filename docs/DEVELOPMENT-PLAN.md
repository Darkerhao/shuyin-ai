# 书引 AI 开发计划与验收标准

## 1. 开发策略

采用分阶段、可验证的业务切片开发。每阶段完成后进行验收，再进入下一阶段。MVP 不包含抖音官方自动发布能力。

## 2. 里程碑

### M0：工程初始化与技术验证
预计 1–2 个工作日。

当前状态（2026-10-23）：核心验收已通过。已实际启动 Tauri 开发版，构建并安装 NSIS 包，启动安装后的程序，核对 SQLite 在进程关闭后保留文字与原时间戳，并观察到原生对话框返回本地 MP4 路径。lint、类型检查、前端 5 测试、Rust 5 测试、Clippy 和构建通过。证据及尚未覆盖的发布场景见 `M0-VERIFICATION.md`。该记录对应 M0 验收；后续 M1 进度见下一节。

任务：
- 初始化或检查 Vue 3 + TypeScript + Vite。
- 初始化或检查 Tauri 2。
- 配置开发、构建、测试命令。
- 建立基础路由与布局。
- 验证 SQLite 读写。
- 验证本地文件选择。
- 建立基础错误处理。
- 验证 Windows 打包。

验收：
- 开发环境可启动。
- Windows 安装包可构建并启动。
- SQLite 写入后重启仍存在。
- 可以选择本地视频。
- 没有未解决的构建错误。

M0 后补充工程能力（2026-10-23）：新增 main 代码推送后的自动语义版本、Windows x64 / macOS ARM64 与 x64 / Linux x64 构建矩阵、GitHub Release 产物汇总和版本提交回流 dev。支持 PR 合并及本地 cherry-pick 后推送，版本提交不重复触发打包。Windows EXE 与 ZIP 已本地构建；macOS/Linux 的原生构建、安装及真实 GitHub 发布需首次远端运行验收。实现与失败恢复见 `RELEASE.md`，不等同于 M5 业务交付完成。

### M1：项目与素材管理

当前状态（2026-10-23）：核心验收完成。项目、素材、工作目录、备份恢复、迁移及重启持久化通过；安装版原生素材选择/取消、默认播放器实际播放、独立 Windows 安装及 0.1.0→0.1.1 升级保留数据通过。自动化与构建通过，完整证据和发布边界见 `M1-VERIFICATION.md`。

预计 2–3 个工作日。

任务：
- 数据库迁移。
- 项目 CRUD、搜索、筛选和归档。
- 素材文件关联。
- 文件存在性检测与重新定位。
- 工作目录管理。
- 基础备份。

验收：
- 项目创建、编辑、查询和归档正常。
- 重启后数据不丢失。
- 删除项目不默认删除源视频。
- 视频路径失效可被识别并重新关联。
- 迁移不会重复破坏数据。

### M2：AI 创作
预计 3–5 个工作日。

任务：
- 文本模型 Provider 接口。
- 至少一个真实可用的模型适配器。
- 模型配置与安全凭据存储。
- 连接测试。
- 大纲、讲稿、标题、描述和话题生成。
- 结果编辑和版本管理。
- AI 任务状态与错误处理。

验收：
- 可调用已配置模型。
- 请求失败有明确提示。
- 输出通过结构校验后才入库。
- 失败不会丢失草稿。
- 可保存并切换历史版本。
- 日志不包含 API Key。
- 更换模型不需要改业务组件。

### M3：封面工坊
预计 2–4 个工作日。

任务：
- 模板数据结构。
- 背景图选择。
- 标题、副标题和品牌标识。
- 字体、字号、颜色和布局。
- 实时预览。
- PNG 导出。
- 封面版本管理。
- 可选图片生成 Provider。

验收：
- 不配置图片 API 也能导出封面。
- 中文显示正常且文字不越界。
- 输出尺寸正确。
- 历史版本不被覆盖。
- 重启后可以恢复编辑配置。

### M4：发布中心
预计 2–3 个工作日。

任务：
- 标题、描述、标签、封面和视频选择。
- 发布任务创建。
- 任务包生成。
- 发布检查清单。
- 一键复制。
- 打开文件和发布入口。
- 发布结果记录。

验收：
- 一键生成完整任务包。
- 视频引用路径正确。
- 缺失视频时不能进入 ready 状态。
- 未确认标题或封面时有提示。
- 中文复制正确。
- 用户确认发布后记录正确状态。
- 任务包生成失败时保留源素材。

### M5：测试、打包与试用
预计 2–4 个工作日。

任务：
- 单元测试和关键流程测试。
- 验证迁移、备份与恢复。
- 验证文件缺失和重新定位。
- 验证模型失败与异常响应。
- 验证 API Key 安全。
- 验证中文封面排版。
- 验证任务包完整性。
- 验证安装、启动、退出和升级。
- 完善用户文档。
- 使用至少 3 个真实书籍项目试用。

验收：
- 核心测试通过。
- 失败场景有明确提示。
- 草稿不会因模型失败丢失。
- 安装包可在目标 Windows 环境启动。
- 备份可恢复。
- 3 个真实项目可完成发布准备流程。
- 无已知高优先级数据丢失问题。

## 3. 总体时间估算

预计 MVP 约 2–4 周，取决于开发者投入、AI 服务调试、Tauri 环境和封面排版复杂度。该估算不包含官方发布权限申请周期。

## 5. 风险与应对

- AI 输出不稳定：结构校验、Prompt 版本、人工审核、保留历史。
- API 不兼容：Provider Adapter 和契约测试。
- 密钥泄漏：系统凭据存储、日志脱敏、最小权限。
- 文件移动：路径检测、重新定位、保留记录。
- 图片服务不可用：本地模板降级。
- 无法取得抖音发布权限：保留半自动发布价值。
- 范围膨胀：冻结 MVP，新增功能需评估对当前验收的影响。
