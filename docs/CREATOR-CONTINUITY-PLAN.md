# 创作连续性优化（2026-11-06）

本轮实施三项已确认的改进：生成可离页、资料与发布准备自动暂存、内容创作首屏优化。复用现有任务、Provider、SQLite 草稿及主题，不引入新依赖。

## 实现约定

1. 文案全量生成、按项调整、时长推荐及封面背景的请求由应用级生成服务持有。服务保存本次运行的状态、取消入口与候选，页面订阅；正式结果仍由现有 Rust 任务校验并入库。不因切页重新提交。原有未采用稿保留；图片完成后明确采用到请求时的尺寸，避免迟到结果覆盖编辑。应用关闭会中断本地请求，关闭前提示；不承诺关闭后继续生成。
2. 草稿仍写 SQLite。扩展 editor_drafts 的所有者键以支持未建立书籍的新建表单及每条发布任务，新发布表单按书籍隔离。保留原 writing/cover 草稿及视频任务自有草稿。书籍资料及待绑定路径、发布文字/素材选择/未完成的定时输入可以暂存，不触发业务保存、文件关联、发布确认或任务包生成。正式保存成功清理对应暂存；失败保留。离页、切任务、正常关闭等待暂存，失败留在原页。
3. 已配置的时长区默认收起，展开偏好只存本机界面设置。压缩创作页头、重复流程导航和生成区；编辑正文与说明字号提高。保留流程快捷键、模型选择、历史对照及深浅主题。

## 验收

- 生成时切换页面/书籍，返回仍能看到同一任务和候选，执行次数为一次，取消后迟到片段不再显示。
- 当前稿不被后台结果覆盖；按项候选需采用；图片需明确应用到目标比例。
- 空书名、待绑定路径、不完整定时时间可暂存；重开恢复；不同任务/书籍互不串稿。
- 暂存失败阻止离页并显示重试入口；正式保存失败原稿保留，成功后不恢复过期暂存。
- v18 升级保留原草稿，备份/恢复保留新草稿，已发布任务只读。
- 1280×720 下首屏能看到发布标题及正文编辑区；深浅主题、键盘焦点和窄窗口布局正常。
- 执行相关前端与 Rust 回归、lint、TypeScript、构建，并记录隔离浏览器与真实桌面/外部服务的验证边界。

业务影响：feat / minor，版本由发布流水线处理。后续用户已授权：完成双轴评审和问题修复后，以中文提交信息提交并推送dev，再将本次提交cherry-pick到main并推送；不手动升版本。
