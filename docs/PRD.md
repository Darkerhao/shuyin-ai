# 书引 AI 产品需求

## 当前范围（2026-10-23 用户确认）

只为每本书准备三项内容：发布标题、发布内容、音频生成提示词。此范围替代原 MVP 的完整创作工作台计划；大纲、完整讲稿、话题候选、封面、素材管理、发布任务包和运营统计不再作为当前迭代目标。

## 使用流程

1. 添加书名，可选填作者和书籍内容或这一期想讲的重点。
2. 点击“一键生成”，一次请求生成一套一致的结果。
3. 编辑需要调整的文字，点击“保存修改”。
4. 分别复制标题、发布内容到发布页面；复制音频提示词到音频生成工具，并在该工具选择对应书籍来源。

不要求先写读书笔记、大纲或讲稿。只有书名时可用一般书籍知识，不编造细节；同名书建议补作者，具体内容以用户资料及音频工具的原书来源为准。

## 三项输出

- 发布标题：一个标题，最多30字，自然、有吸引力、不夸大。
- 发布内容：一段可直接发布的作品介绍，最多1000字，默认短句换行；不附话题、制作备注或分析清单。
- 音频生成提示词：Markdown，可直接复制到音频工具的自定义指导输入框。它是生成音频的提示词，不是完整口播稿，也不在本应用生成音频文件。

## 音频节目默认规则

- 主持人：甲子；系列：十分钟读懂一本书。
- 时长：8—10分钟；语言：简体中文。
- 通俗、幽默、有故事感，像播客讲故事，面向普通观众。
- 注意中文多音字、人名地名读音；避免学术化；故事、案例或观点为主，分析为辅；节奏清晰。
- 固定系列开场与关注结尾由模板保留，书籍引入和五段主题随每本书调整。
- 历史书围绕背景、人物、事件与阅读价值；小说围绕人物、冲突与主题；非虚构围绕问题、观点、案例与现实联系。不把所有书套成明朝历史故事。
- 避免编造引文、页码、情节或虚构人物对白；音频工具必须参考用户上传/选择的书籍来源。

## 页面与数据

主导航只有我的书籍和模型设置。书籍表单只保留书名、作者和补充内容；结果页只保留三项输出、生成、复制、保存，历史版本折叠显示。目录和备份在模型设置页提供辅助入口。

保留已存在的书籍、素材引用和旧版本数据；旧五类结果不自动转换或删除。新生成和编辑均以一套三项结果追加保存。失败、超时或取消不覆盖已保存内容及当前修改。

沿用统一文本 Provider 与系统凭据。API Key 不写入普通配置、SQLite、备份、源码或日志。无新增依赖。

## 验收

- 只有书名也能完成生成，三项一次返回，数量和长度通过校验。
- 音频提示词保持固定系列话术，至少两本不同体裁书籍的五段结构不同。
- 可编辑、分别复制，中文换行不丢失；复制失败有提示。
- 生成中编辑、保存失败和取消均不丢稿；历史可切换。
- v3→v4 保留历史内容、任务引用、模型及凭据引用；旧备份可恢复。
