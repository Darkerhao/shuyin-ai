# 书引 AI 产品需求

## 当前范围（2026-10-24）

为每本书准备三项内容：发布标题、发布内容、音频生成提示词。M3 封面工坊和 M4 发布准备均作为书籍内的独立入口。用户在确认启动条件后继续实施 M4。大纲、完整讲稿、话题候选和运营统计仍不在当前迭代范围。

## 使用流程

1. 添加书名，可选填作者和书籍内容或这一期想讲的重点。
2. 点击“一键生成”，一次请求生成一套一致的结果。
3. 编辑需要调整的文字，点击“保存修改”。
4. 分别复制标题、发布内容到发布页面；复制音频提示词到音频生成工具，并在该工具选择对应书籍来源。
5. 完成视频制作和双比例封面导出后进入「发布准备」，选择本地视频、两张封面，确认标题和封面，生成完整任务包。
6. 在抖音创作者中心自行上传、确认预览并发布；回到应用手动确认发布成功，记录时间、可选作品链接和备注。

不要求先写读书笔记、大纲或讲稿。只有书名时可用一般书籍知识，不编造细节；同名书建议补作者，具体内容以用户资料及音频工具的原书来源为准。

## 三项输出

- 发布标题：一个标题，最多30字，自然、有吸引力、不夸大。
- 发布内容：一段可直接发布的作品介绍，最多1000字，默认短句换行；不附话题、制作备注或分析清单。
- 音频生成提示词：Markdown，可直接复制到音频工具的自定义指导输入框。它是生成音频的提示词，不是完整口播稿，也不在本应用生成音频文件。

## 音频节目默认规则

- 主持人：甲子；系列：十分钟读懂一本书。
- 时长：8—10分钟；语言：简体中文。
- 通俗、幽默、有故事感，像播客讲故事，面向普通观众。
- 注意中文多音字、人名地名读音；避免学术化；故事、案例或观点为主，分析为辅；节奏清晰。
- 固定系列开场与关注结尾由模板保留，书籍引入和五段主题随每本书调整。
- 历史书围绕背景、人物、事件与阅读价值；小说围绕人物、冲突与主题；非虚构围绕问题、观点、案例与现实联系。不把所有书套成明朝历史故事。
- 避免编造引文、页码、情节或虚构人物对白；音频工具必须参考用户上传/选择的书籍来源。

## 页面与数据

主导航只有我的书籍和模型设置。书籍表单只保留书名、作者和补充内容；结果页只保留三项输出、生成、复制、保存，历史版本折叠显示。目录和备份在模型设置页提供辅助入口。

书籍资料和结果页增加「制作封面」入口，不要求先配置模型或生成文案。

## M3 发布图片封面

- 两个本地模板：纸页、深林。可设置主标题、副标题、品牌文字、系统宋体/黑体、字号、三种纵向位置、左对齐/居中及颜色。
- 背景可用纯色或本地 PNG/JPEG/WebP（≤15 MB、≤4000万像素），图片居中裁切铺满，蒙层可调。复用书籍素材引用；缺失时提示重新选择或读取，不删除历史配置。
- 预览与导出共用完整分辨率 Canvas。中文按字素测宽换行，长文字自动缩小，仍放不下时明确阻止导出。
- 用于发布作品时上传的两张图片封面：横版 4:3（1440×1080）和竖版 3:4（1080×1440）PNG。编辑同一套文字、背景及样式，可切换预览比例，一次导出两张分别排版的图片；无需图片 API。
- 两张图均排版成功后才开始写入；每张单独保存版本。第二张写入失败保留第一张、显示成功路径并保留草稿，可重试。
- 新制作只提供上述两种比例。旧尺寸历史及文件原样保留；恢复旧配置继续编辑时按横/竖方向转换为 4:3 / 3:4，方形转为 3:4，并提示转换。
- 每次保存配置或导出都追加历史版本。PNG 写入项目目录的 covers 子目录，不覆盖已有文件；重启恢复最新保存配置，可切回旧版继续编辑。
- 保存/导出失败保留页面草稿；切换历史、离开页面及关闭窗口提示未保存内容。未保存草稿不承诺崩溃恢复。
- AI 生成封面是用户可选的制作方式：配置图片模型后可主动选择 AI 生成；不启用或不配置时仍可使用本地模板和图片。AI 生成背景与视觉素材，中文文字沿用程序排版，最终同样导出横版 4:3 和竖版 3:4 两张封面；失败或取消不得覆盖当前草稿、背景或历史版本。
- 本地制作、双比例导出和可选 AI 背景已实现。模型设置支持独立图片用途及默认模型；图片服务须兼容 GPT Image 的 `/images/generations`，返回一张 base64 静态 PNG、JPEG 或 WebP。生成成功只应用背景，不自动保存或导出；确认预览后由用户导出两张封面。Windows 本机契约服务及 UGQ.ai gpt-image-2 外部实测均已通过。
- 原图片仅关联，数据库备份不包含图片或 PNG 文件；需要另行保管源图和导出目录。

保留已存在的书籍、素材引用和旧版本数据；旧五类结果不自动转换或删除。新生成和编辑均以一套三项结果追加保存。失败、超时或取消不覆盖已保存内容及当前修改。

沿用统一文本 Provider 与系统凭据。API Key 不写入普通配置、SQLite、备份、源码或日志。无新增依赖。

## 验收

M4 验收与实现边界另见 `M4-VERIFICATION.md`。发布草稿可以缺少素材；就绪任务必须有可用视频、两张指定比例封面、非空发布文字及人工确认。任务包保留视频引用路径并复制两张封面，任何失败不删除原视频、旧封面或旧任务包。改动草稿、素材失效或路径变化后需要重新生成；发布成功仅在用户明确确认后记录。

- 只有书名也能完成生成，三项一次返回，数量和长度通过校验。
- 音频提示词保持固定系列话术，至少两本不同体裁书籍的五段结构不同。
- 可编辑、分别复制，中文换行不丢失；复制失败有提示。
- 生成中编辑、保存失败和取消均不丢稿；历史可切换。
- v3→v4 保留历史内容、任务引用、模型及凭据引用；旧备份可恢复。
