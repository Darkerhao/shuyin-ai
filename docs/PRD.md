## AI 发布标签（2026-11-04）

发布准备明确选择文案来源后同时带入标题、内容和标签，允许修改或清空；替换已有文字或标签须确认，取消保留原值。任务固定本次文字快照，辅助发布沿用既有填写与回读，将标签追加到抖音正文末尾，继续操作不重复追加。用户仍在官方页面检查并亲自发布。

旧文案缺标签时显示为空，可通过「按项调整」只选择「发布标签」，预览后采用，不修改未选中的内容。模型缺少标签或返回不合法格式时拒绝本次结果，失败与停止保留当前稿和历史。复用统一Provider、现有版本/草稿/发布任务，不增加模型请求、依赖或SQL迁移，schema17不变；旧历史JSON不批量回填。

## 续作、缓存备份与模型诊断（2026-11-03）

书架卡片与最近创作入口根据已有任务、草稿和保存版本推导当前工作：正在执行的任务优先，其余按最近活动选择。入口可直达具体视频、音频或发布任务，按钮显示“正在渲染视频”“继续确认分镜”等对应状态。页面顶部持续显示全局运行任务，点击可返回该任务；等待登录/人工确认仍可从书架续作，不显示为正在运行。此功能只定位任务，不自动重试、提交或发布，也不新增一套持久化流程状态。

“数据与备份”增加各书工作目录占用和可清理缓存。先扫描，再预览文件清单，确认后只删除已知视频任务内可重建的渲染缓存和试片文件；正在运行的视频、登记素材、导出封面、发布任务包、全部运行目录和目录链接保留。外部关联素材不计入目录占用，未知目录不自动清理；清理后试片须重新生成。预览内容变化时要求重新预览。

完整备份和仅数据库备份成功后记录时间与类型，失败保留上次成功记录；设置页在无记录或距上次成功满7天时提醒备份，不自动执行备份。模型诊断显示最近200次实际请求的模型、阶段、状态、首响应、总耗时和服务返回的输入/输出/总token。首响应明确指收到HTTP响应头，不是首个正文token；未返回用量显示“—”，不估算。成功响应不代表内容已通过业务校验或用户已采用；取消和重启中断分别记录，不保存请求正文、响应正文或密钥。

这三项为兼容功能增强，使用现有续作、备份及Provider流程，无新增依赖。schema升级至17；实现和实机证据见[剩余三项验收](CREATOR-COMPLETION-VERIFICATION.md)。

## 单镜重新生成（2026-11-03）

完整分镜准备后，每镜可“重新生成这一镜”：填写修改要求、选择本次文本模型，先对照当前与候选的标题、构图、场景、景别、物体、动作及字幕锚点，再明确采用或放弃。单镜请求使用当前编辑内容，包括未正式保存的修改；要求字幕和分镜结构合法，镜头范围与原任务一致。

只替换选中镜头，不拆镜、不合镜、不改变字幕或时间码，也不丢失其他镜头的未保存修改。图片镜头保留图片、裁切与来源，仅调整标题和画面布局字段。候选生成不会改正式计划；采用进入现有自动草稿，保存校对和试片继续使用原流程。失败、停止、放弃及过期候选保留原编辑；关闭未采用候选不保存候选。正在执行或已完成的视频不能直接改写。

## 视频运行环境一键检查（2026-11-03）

视频运行环境配置区提供“一键检查环境”。按“从原声新转写字幕”或“使用已有SRT/已保存字幕”检查当前路径，逐项显示Node、Frametell、FFmpeg、浏览器、字体、Python及本地语音模型的实际状态、版本和路径。使用已有字幕时Python与模型标为“不需要”。

## 视频自动草稿与逐句校对（2026-11-03）

字幕、分镜及校对位置按视频任务自动暂存，停止编辑约400ms后写入SQLite，显示等待、写入、成功和失败状态；离页、切换任务及正常关闭等待暂存，失败保留当前编辑。重开视频页优先恢复最近编辑的任务，明确任务链接优先。自动草稿不改正式计划，不启动AI或渲染；正式保存、重建和渲染仍使用原校验与确认流程。

逐句显示原文与当前校对文，支持只看修改项、修改正文、恢复一句原文和播放该句时间窗内的任务原声。长字幕每页20句，保留完整SRT编辑入口；两种编辑共用同一字幕文本，单句操作不改时间码。原文缺失或时间码无法对应时明确提示，不能用已校对文冒充原文。重启恢复句子/分镜位置、筛选及完整SRT光标；强制终止前尚未写入的输入不保证恢复。

## 使用流程

1. 添加书名，可选填作者和书籍内容或这一期想讲的重点。
2. 点击“一键生成”，一次请求生成一套一致的结果。
3. 编辑需要调整的文字，自动暂存后可离页或重启继续；点击“保存修改”才追加正式历史。也可按项重新生成，预览后采用。
4. 在「音频制作」选择原书文件或资料文本，确认格式与完整指导后启动自动任务；首次在独立 Chrome 完成 Google 登录。应用自动新建专属笔记本、添加来源、生成、下载并归档音频；也可继续手动打开 Gemini Notebook 并导入下载成品。
   随后可在「视频制作」识别字幕、确认分镜并生成原声 MG 成片，也可使用剪映等外部工具。封面提示词分别复制到图片工具并选择对应比例；也可点击「使用这些内容制作封面」。
5. 完成成片和三种比例封面导出后进入「发布准备」，明确选择文案历史版本或手动填写，选择制作音频、最终成片并核对两张封面，确认后生成完整任务包。发布检查验证 MP4/MOV 时长可读取、画面可读取且包含音轨，不限制横竖屏比例。
6. Windows 可在「应用内抖音辅助发布」打开官方窗口，扫码并核对账号后，上传已就绪任务的视频、填写标题/内容及横竖封面；也可沿用任务包手动上传。检查官方预览、声明和发布设置后亲自发布，再回到应用确认实际结果，记录时间、可选作品链接和备注。

不要求先写读书笔记、大纲或讲稿。只有书名时可用一般书籍知识，不编造细节；同名书建议补作者，具体内容以用户资料及音频工具的原书来源为准。

## 生成输出

- 发布标题：一个标题，最多30字，自然、有吸引力、不夸大。
- 发布内容：一段可直接发布的作品介绍，最多1000字，默认短句换行；不附话题、制作备注或分析清单。
- 发布标签：独立的空格分隔 `#标签` 字符串，建议3—5个，最多500字；结合书籍和本期主题生成，辅助发布时追加到正文末尾。
- 音频生成提示词：Markdown，可直接复制，也可由 Windows 应用内自动任务完整写入 Gemini Notebook。它是生成音频的指导，不是完整口播稿；应用通过外部网站生成并归档音频，不自行合成语音。
- 封面主标题：最多30字，建议6—14字，提炼本书的悬念、冲突或核心问题，与发布标题区分。
- 封面副标题：最多60字，建议10—24字，包含书名并补充具体看点，不使用固定系列名充数。
- 横版/竖版封面提示词：各最多2000字，分别明确 4:3（1440×1080）与 3:4（1080×1440），同一主题下独立组织横向场景和纵向层次；含主体、场景、光线、色彩、情绪与中央文字留白，不仅替换尺寸。只生成无字背景，中文标题由后期排版添加。

## 音频节目默认规则

- 主持人：甲子；系列为「读懂一本书」，口播不作分钟数承诺。
- 时长：按书籍的AI推荐或手动设置；语言：简体中文。
- 通俗、幽默、有故事感，像播客讲故事，面向普通观众。
- 注意中文多音字、人名地名读音；避免学术化；故事、案例或观点为主，分析为辅；节奏清晰。
- 固定系列开场与关注结尾由模板保留，书籍引入和五段主题随每本书调整。
- 历史书围绕背景、人物、事件与阅读价值；小说围绕人物、冲突与主题；非虚构围绕问题、观点、案例与现实联系。不把所有书套成明朝历史故事。

逐篇进入原发布准备页，使用同一辅助流程；在官方页面检查并亲自发布后，再人工确认实际时间、可选链接和备注。只有记录事务成功才释放该任务的上传会话，随后可回列表继续下一篇；列表不会自动发起上传。已发布列表显示实际记录并可复制链接。新任务仍明确选择来源，不默认套用另一篇或最新文案；不新增数据库、会话持久化或平台抓取。安装版证据与模拟记录边界见 `M7-VERIFICATION.md`。

## M3 发布图片封面

- 两个本地模板：纸页、深林。可设置主标题、副标题、品牌文字、系统宋体/黑体、字号、三种纵向位置、左对齐/居中及颜色。
- 新封面自动带入已保存结果中的主副标题，作为待保存草稿；已有封面保持文字、背景和样式，点击「使用这组主副标题」才应用。封面页可切换和复制两种提示词，或主动用于 AI 背景。普通入口使用最新结果，结果页直达入口使用当前选中的版本。
- 内置图片模型仍生成一张可按三种比例裁切的背景，图片提示词用作画面创意；不承诺原始图片就是目标比例。需要独立构图时将对应提示词复制到外部工具，并选择对应比例；最终本地 PNG 导出尺寸严格为三种指定尺寸。
- 背景可用纯色或本地 PNG/JPEG/WebP（≤15 MB、≤4000万像素），支持拖动裁切位置、水平/垂直滑块和1–3倍缩放，可重置居中。三个比例并排预览，与导出使用相同裁切配置。复用书籍素材引用；缺失时提示重新选择或读取，不删除历史配置。
- 预览与导出共用完整分辨率 Canvas。中文按字素测宽换行，长文字自动缩小，仍放不下时明确阻止导出。
- 支持横版 4:3（1440×1080）、竖版 3:4（1080×1440）和横版 16:9（1920×1080）PNG。编辑同一套文字、背景及样式，可切换预览比例，一次导出三张分别排版的图片；无需图片 API。发布准备仍选用 4:3 和 3:4 两张封面，16:9 可用于其他横屏场景。
- 三张图均排版成功后才开始写入；每张单独保存版本。任一张写入失败保留已成功的版本、显示成功路径并保留草稿，可重试。
- 新制作提供上述三种比例。旧尺寸历史及文件原样保留；已有 1920×1080 配置按 16:9 恢复，其他不支持的旧尺寸继续按横/竖方向转换为 4:3 / 3:4，方形转为 3:4，并提示转换。
- 每次保存配置或导出都追加历史版本，自动暂存不追加历史。PNG 写入项目目录的 covers 子目录，按「书名-比例-尺寸-v版本.png」命名，例如 `围城-3比4-1080x1440-v3.png`；版本与封面历史一致，同名文件或目录占用时递增版本，不覆盖已有文件。AI 背景按实际比例、尺寸命名，额外标注「背景」并独立递增版本；书名统一处理非法字符、保留名及长度。旧文件及引用不改名；重启优先恢复草稿，否则恢复最新保存配置，可切回旧版继续编辑。
- 保存/导出失败保留草稿；部分导出成功仍保留草稿。个人封面样式可保存、应用和删除，复用品牌、字体、字号、颜色、蒙层与布局；不带入另一本书的标题、背景、尺寸和裁切位置，应用后可单独调整。
- AI 生成封面是用户可选的制作方式：配置图片模型后可主动选择 AI 生成；不启用或不配置时仍可使用本地模板和图片。AI 生成背景与视觉素材，中文文字沿用程序排版，最终同样导出 4:3、3:4 和 16:9 三张封面；失败或取消不得覆盖当前草稿、背景或历史版本。
- 本地制作、三比例导出和可选 AI 背景已实现。模型设置支持独立图片用途及默认模型；图片服务须兼容 GPT Image 的 `/images/generations`，返回一张 base64 静态 PNG、JPEG 或 WebP。生成成功只应用背景，不自动保存或导出；确认预览后由用户导出三张封面。Windows 本机契约服务及 UGQ.ai gpt-image-2 外部实测均已通过。
- 原图片仅关联；完整备份包含登记的图片与 PNG，单独数据库备份只包含配置与路径。

保留已存在的书籍、素材引用和旧版本数据；旧五类结果不自动转换或删除。新生成以一套七项结果追加保存；旧三项版本的封面字段显示为空，仍可编辑保存或再次生成完整结果。失败、超时或取消不覆盖已保存内容及当前修改。

沿用统一文本 Provider 与系统凭据。API Key 不写入普通配置、SQLite、备份、源码或日志。备份校验直接复用锁文件中已有的 sha2，不增加压缩依赖。

## 验收

2026-10-25 新增「关于与更新」辅助入口：显示真实应用版本与本版更新内容；默认每次启动自动检查并后台下载签名更新包，可关闭自动模式、手动检查和下载。发现新版本后在全局提示，可查看更新说明和下载进度；下载校验成功后需人工确认安装并重启，不能打断创作自动安装。失败显示原因并可重试；关闭自动模式的设置保存在 SQLite，重启保持。正式签名包与更新清单随原发布流水线交付；首次启用和跨平台安装验收边界见 `RELEASE.md`。

M4 验收与实现边界另见 `M4-VERIFICATION.md`。发布草稿可以缺少素材；就绪任务必须有可用音频、含音轨的最终成片、两张指定比例封面、非空发布文字及人工确认。任务包保留音频与视频引用路径并复制两张封面，任何失败不删除原视频、旧封面或旧任务包。改动草稿、素材失效或路径变化后需要重新生成；发布成功仅在用户明确确认后记录。

M5 还要求任务包内封面与源导出文件内容一致；即使损坏后的文件大小相同，也必须撤销就绪状态。整体测试、迁移恢复、Windows 安装升级及三本书试用的证据与范围见 `M5-VERIFICATION.md`。

- 只有书名也能完成生成，七项一次返回；封面字段必填、长度与比例标识通过校验后才能写入。

- 可编辑、分别复制，中文换行不丢失；复制失败有提示。
- 生成中编辑、保存失败和取消均不丢稿；历史可切换。
