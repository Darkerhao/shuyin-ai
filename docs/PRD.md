# 书引 AI 产品需求

## 当前范围（2026-10-24）

为每本书一次准备发布标题、发布内容、音频生成提示词，以及封面主标题、副标题、横版 4:3 和竖版 3:4 的图片提示词。封面文案与画面须基于书籍资料和本期重点，有具体看点与故事张力，不编造情节或夸大宣传。M3 封面工坊和 M4 发布准备均作为书籍内的独立入口。M5 历史验收记录保留；本轮新增封面素材生成，不重新启用大纲、完整讲稿、话题候选和运营统计。

## 使用流程

1. 添加书名，可选填作者和书籍内容或这一期想讲的重点。
2. 点击“一键生成”，一次请求生成一套一致的结果。
3. 编辑需要调整的文字，点击“保存修改”。
4. 分别复制标题、发布内容到发布页面；复制音频提示词到音频生成工具，并在该工具选择对应书籍来源。
   封面提示词分别复制到图片工具并选择对应比例；也可点击「使用这些内容制作封面」，有修改时先保存，并以当前选中结果作为封面素材来源。
5. 完成视频制作和三种比例封面导出后进入「发布准备」，选择本地视频、两张封面，确认标题和封面，生成完整任务包。
6. 在抖音创作者中心自行上传、确认预览并发布；回到应用手动确认发布成功，记录时间、可选作品链接和备注。

不要求先写读书笔记、大纲或讲稿。只有书名时可用一般书籍知识，不编造细节；同名书建议补作者，具体内容以用户资料及音频工具的原书来源为准。

## 生成输出

- 发布标题：一个标题，最多30字，自然、有吸引力、不夸大。
- 发布内容：一段可直接发布的作品介绍，最多1000字，默认短句换行；不附话题、制作备注或分析清单。
- 音频生成提示词：Markdown，可直接复制到音频工具的自定义指导输入框。它是生成音频的提示词，不是完整口播稿，也不在本应用生成音频文件。
- 封面主标题：最多30字，建议6—14字，提炼本书的悬念、冲突或核心问题，与发布标题区分。
- 封面副标题：最多60字，建议10—24字，包含书名并补充具体看点，不使用固定系列名充数。
- 横版/竖版封面提示词：各最多2000字，分别明确 4:3（1440×1080）与 3:4（1080×1440），同一主题下独立组织横向场景和纵向层次；含主体、场景、光线、色彩、情绪与中央文字留白，不仅替换尺寸。只生成无字背景，中文标题由后期排版添加。

## 音频节目默认规则

- 主持人：甲子；系列：十分钟读懂一本书。
- 时长：8—10分钟；语言：简体中文。
- 通俗、幽默、有故事感，像播客讲故事，面向普通观众。
- 注意中文多音字、人名地名读音；避免学术化；故事、案例或观点为主，分析为辅；节奏清晰。
- 固定系列开场与关注结尾由模板保留，书籍引入和五段主题随每本书调整。
- 历史书围绕背景、人物、事件与阅读价值；小说围绕人物、冲突与主题；非虚构围绕问题、观点、案例与现实联系。不把所有书套成明朝历史故事。
- 避免编造引文、页码、情节或虚构人物对白；音频工具必须参考用户上传/选择的书籍来源。

## 按项调整（2026-10-25）

- 已有一套内容后，可以勾选七项中的一项或多项，选填最多2000字的修改要求，再生成候选结果。
- 生成前先保存当前修改；保存失败则不调用模型。调整使用当前选中的已保存版本，未选中字段由程序原样保留。
- 候选结果逐项显示原内容和新内容，只有点击「采用并保存新版本」才追加正式版本；放弃不改变当前内容和历史版本。生成与预览期间暂时锁定原文编辑，避免采用时覆盖新输入。
- 候选生成失败、取消或采用保存失败都保留原内容；采用失败保留预览以便重试。模型返回额外字段、漏项、超长内容或错误封面比例时拒绝结果，不自动重试。
- 音频只调整书籍引入和五段指导，仍由同一音频模板保留主持人、系列、时长与固定开场结尾。沿用统一 Provider、120秒超时、取消和系统凭据。
- 候选暂存于任务记录，采用后关联正式版本。预览不承诺跨重启恢复；历史版本始终追加，不覆盖。

## 页面与数据

主导航只有我的书籍和模型设置。书籍表单保留书名、作者和补充内容；结果页显示七项输出，支持编辑、单项复制、保存和直接进入制作封面，历史版本折叠显示。目录和备份在模型设置页提供辅助入口。

书籍资料和结果页增加「制作封面」入口，不要求先配置模型或生成文案。

界面统一采用 shadcn-vue。2026-10-25 已覆盖侧栏、书架、书籍表单、内容创作、封面工坊、发布准备、模型设置、目录备份、素材管理及技术验证页。沿用暖白背景、清晰灰阶正文和墨绿主操作，统一按钮、输入、下拉选择、复选框、蒙层滑块、标签页、折叠区和状态标签。保留已有搜索、筛选、排序、新建、失败保稿和本地数据边界；切换历史取消时保留原选项与草稿，保存和素材刷新后下拉框同步展示最新状态。

## M3 发布图片封面

- 两个本地模板：纸页、深林。可设置主标题、副标题、品牌文字、系统宋体/黑体、字号、三种纵向位置、左对齐/居中及颜色。
- 新封面自动带入已保存结果中的主副标题，作为待保存草稿；已有封面保持文字、背景和样式，点击「使用这组主副标题」才应用。封面页可切换和复制两种提示词，或主动用于 AI 背景。普通入口使用最新结果，结果页直达入口使用当前选中的版本。
- 内置图片模型仍生成一张可按三种比例裁切的背景，图片提示词用作画面创意；不承诺原始图片就是目标比例。需要独立构图时将对应提示词复制到外部工具，并选择对应比例；最终本地 PNG 导出尺寸严格为三种指定尺寸。
- 背景可用纯色或本地 PNG/JPEG/WebP（≤15 MB、≤4000万像素），图片居中裁切铺满，蒙层可调。复用书籍素材引用；缺失时提示重新选择或读取，不删除历史配置。
- 预览与导出共用完整分辨率 Canvas。中文按字素测宽换行，长文字自动缩小，仍放不下时明确阻止导出。
- 支持横版 4:3（1440×1080）、竖版 3:4（1080×1440）和横版 16:9（1920×1080）PNG。编辑同一套文字、背景及样式，可切换预览比例，一次导出三张分别排版的图片；无需图片 API。发布准备仍选用 4:3 和 3:4 两张封面，16:9 可用于其他横屏场景。
- 三张图均排版成功后才开始写入；每张单独保存版本。任一张写入失败保留已成功的版本、显示成功路径并保留草稿，可重试。
- 新制作提供上述三种比例。旧尺寸历史及文件原样保留；已有 1920×1080 配置按 16:9 恢复，其他不支持的旧尺寸继续按横/竖方向转换为 4:3 / 3:4，方形转为 3:4，并提示转换。
- 每次保存配置或导出都追加历史版本。PNG 写入项目目录的 covers 子目录，不覆盖已有文件；重启恢复最新保存配置，可切回旧版继续编辑。
- 保存/导出失败保留页面草稿；切换历史、离开页面及关闭窗口提示未保存内容。未保存草稿不承诺崩溃恢复。
- AI 生成封面是用户可选的制作方式：配置图片模型后可主动选择 AI 生成；不启用或不配置时仍可使用本地模板和图片。AI 生成背景与视觉素材，中文文字沿用程序排版，最终同样导出 4:3、3:4 和 16:9 三张封面；失败或取消不得覆盖当前草稿、背景或历史版本。
- 本地制作、三比例导出和可选 AI 背景已实现。模型设置支持独立图片用途及默认模型；图片服务须兼容 GPT Image 的 `/images/generations`，返回一张 base64 静态 PNG、JPEG 或 WebP。生成成功只应用背景，不自动保存或导出；确认预览后由用户导出三张封面。Windows 本机契约服务及 UGQ.ai gpt-image-2 外部实测均已通过。
- 原图片仅关联，数据库备份不包含图片或 PNG 文件；需要另行保管源图和导出目录。

保留已存在的书籍、素材引用和旧版本数据；旧五类结果不自动转换或删除。新生成以一套七项结果追加保存；旧三项版本的封面字段显示为空，仍可编辑保存或再次生成完整结果。失败、超时或取消不覆盖已保存内容及当前修改。

沿用统一文本 Provider 与系统凭据。API Key 不写入普通配置、SQLite、备份、源码或日志。无新增依赖。

## 验收

M4 验收与实现边界另见 `M4-VERIFICATION.md`。发布草稿可以缺少素材；就绪任务必须有可用视频、两张指定比例封面、非空发布文字及人工确认。任务包保留视频引用路径并复制两张封面，任何失败不删除原视频、旧封面或旧任务包。改动草稿、素材失效或路径变化后需要重新生成；发布成功仅在用户明确确认后记录。

M5 还要求任务包内封面与源导出文件内容一致；即使损坏后的文件大小相同，也必须撤销就绪状态。整体测试、迁移恢复、Windows 安装升级及三本书试用的证据与范围见 `M5-VERIFICATION.md`。

- 只有书名也能完成生成，七项一次返回；封面字段必填、长度与比例标识通过校验后才能写入。
- 音频提示词保持固定系列话术，至少两本不同体裁书籍的五段结构不同。
- 可编辑、分别复制，中文换行不丢失；复制失败有提示。
- 生成中编辑、保存失败和取消均不丢稿；历史可切换。
- v3→v4 保留历史内容、任务引用、模型及凭据引用；旧备份可恢复。
- 封面素材扩展不修改数据库 schema v7；旧三项 JSON 原样保留，新字段随版本备份恢复。当前版本直达、失败保稿与已有封面不自动覆盖均须有回归。
