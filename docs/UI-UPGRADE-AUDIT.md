## 建议顺序与验收

1. **保护与定位**：个人样式确认、书籍资料退出保护、任务 URL。验收：取消不写入；关闭不静默丢失已编辑资料；刷新/返回仍定位当前任务。
2. **连续创作**：页签/筛选保留、音频直达、封面吸顶及窄窗口。验收：返回条件不重置；音频入口正确；预览无覆盖；900 px 窗口中预览和主操作易达。
3. **反馈与确认**：缺失项入口、备份离页结果、当前操作提示、确认焦点。验收：缺失项可就近补齐；长任务结果可见；键盘能进入、取消并返回发起位置。
4. **逐页视觉收尾**：统一资料/模型/备份/素材的层级、间距和字号，最后处理关于与诊断。验收：共享控件一致、无横向溢出、固定区域不覆盖焦点、主要操作清楚。

以上为最初排查时的建议；后续实施及剩余边界以本报告顶部记录为准。
