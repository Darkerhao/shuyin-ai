# 书引 AI 使用手册

## Gemini Notebook 应用内自动音频（2026-10-29）

Windows 版无需安装 Chrome 扩展：

1. 在音频制作选择本书文档或资料文本、格式，确认完整指导和时长后点击「开始生成音频」。
2. 应用打开专用网站窗口。需要时自行完成 Google 登录、验证码及二次验证；会话独立于 Chrome。Google 拒绝当前环境时按提示处理，不导入 Cookie 或重复生成。
3. 网站可用时自动创建专属笔记本、添加资料、填写指导和提交一次生成。保持书引 AI 运行；关闭网站窗口只隐藏，「查看网站」重新显示。
4. 成品下载到本书任务缓存并校验，复制到 audio/ 后登记；失败时按「重试下载并归档」，不要重新生成。
5. 暂停/停止仅停止本地操作，不取消 Google 已提交生成；重启先核对原 Notebook。旧“等待扩展”任务可在应用内继续。
6. 页面或原任务无法确认时保留数据等待处理；手动下载仍可通过下方「导入音频成品」登记。

真实 Google 登录/生成/下载尚待验收，不保证官方站点支持内置浏览器。格式、时长、额度和权限以实际页面为准。macOS/Linux 暂手动导入，旧扩展可自行卸载。

## 封面字号与配色推荐

一键生成后，「封面素材」会展示 AI 推荐的主副标题字号、各自颜色、点缀色和底色。点击制作新封面会自动带入；已有封面进入「排版样式」后点击「应用 AI 推荐排版」。旧内容可在「按项调整」只勾选「封面字号与配色」，预览并采用后再进入封面工坊。

在「排版样式 → 推荐样式」中点击纸页、深林、黑金焦点、赤焰醒目或蓝调纪实卡片，即可应用整套字号、字体、配色、蒙层与布局。主标题色、副标题色和点缀色均可单独调整，点缀色用于品牌文字与装饰短线。保存为个人样式可跨书复用；导出前检查三种比例中主副标题的清晰度，复杂背景可提高底色蒙层。图片模型仅生成无字背景，正式中文仍由应用排版。

适用范围：七项生成与按项调整、自动草稿、Gemini Notebook 自动音频与手动导入、三比例封面和个人样式、资料导入、半自动发布及完整备份。应用内自动音频仅实现 Windows x64，本地隔离与真实 Google 验收分开。

## 1. 安装与第一次使用

运行 Windows 安装包，按安装器提示完成安装并启动「书引 AI」。ZIP 版需先解压到固定目录，再运行程序；两种方式均依赖 WebView2，业务数据保存在系统用户目录。

安装升级前先保存正在编辑的内容，并在「数据与备份」创建完整备份。正常关闭应用后运行新安装包，使用同一安装目录。升级后检查已有书籍、历史版本及模型连接；不要通过删除数据库处理升级错误。

正式应用数据库默认位于 `%LOCALAPPDATA%\com.shuyin.desktop\shuyin.sqlite3`。界面的「数据库位置」显示实际路径。更改工作目录只影响以后创建的书籍，不移动已有文件，也不改变数据库位置。可把工作目录设在 D 盘。

新建书籍的项目文件夹直接使用书名，例如 `projects/三体`，重名时依次为 `三体 (2)`、`三体 (3)`。书名中的文件名禁用字符会替换，过长名称会截短，应用内完整书名保留。已有项目目录及后续修改书名时的目录保持原位置，避免素材引用失效。

隔离验收包名称含 `Verification`，使用独立数据库与凭据，不是正式安装的升级包。

2026-10-24 的本机 M5 交付已将 `D:\MyWork\software\shuyin-ai` 从 0.1.0 升级到本地验收构建 0.5.1，旧数据库记录保留。原程序、原安装包和数据库副本位于仓库 `output/playwright/m5-formal/rollback/`。可交付 EXE、ZIP 和校验清单位于 `output/delivery/m5-windows-0.5.1/`；该目录明确标记为本地构建，未代替 GitHub 正式发布。

## 2. 配置文本模型

进入「模型设置」，选择「文本 · 发布文案」，填写服务名称、可信服务的 API 根地址、模型 ID 和 API Key，勾选启用及默认模型后保存，再点击「测试连接」。

- 根地址通常以 `/v1` 结束；程序追加 `/chat/completions`，不要填写完整聊天接口地址。
- 根地址和模型 ID 以你的服务实际配置为准。服务需支持完整文本响应；连接成功后仍需用一本书检查内容生成。
- API Key 存在操作系统凭据库，普通设置和数据库备份不包含密钥。编辑已有配置时留空会保留原密钥；更换服务地址须重新输入。
- 配置多个文本模型后，可以在文案页选择本次使用的模型。请求可能产生服务费用，失败后由你决定是否重试。

图片模型可选。选择「图片 · AI 封面背景」，保存支持 `/images/generations`、返回 base64 静态 PNG/JPEG/WebP 的服务配置，在封面页主动生成背景。没有图片模型也能完整制作本地封面。

## 3. 添加书籍并准备文案

1. 在「我的书籍」点击「新建项目」，填写书名。建议补充作者、原书资料或本期重点，避免同名书和内容理解偏差。可在「本地书籍文件」点击「选择本地文件」，绑定 PDF、EPUB、DOCX、TXT、Markdown；核对文件名及路径，保存前可取消绑定。保存并继续后，「音频制作」会默认选中本书可用的文档，可直接生成，无需再次选择电脑文件。绑定仅记录路径，文件应保留在原位置；缺失时到「发布准备 → 关联视频 / 重新定位素材」重新定位，也可在此移除关联。已有书籍可回到「书籍资料」继续添加文件。
2. 点击「保存并继续」。首次进入创作页会用文本模型推荐音频时长并说明依据；可在「音频目标时长（分钟）」自由修改或使用快捷选项，也可点击「AI 推荐时长」重新估计。支持1—1440分钟整数。确认后点击「一键生成」，目标时长会自动保存，并生成发布标题、发布内容、音频制作指导、封面主副标题与两种比例图片提示词。时长也可单独保存，离页和正常关闭前会等待保存，失败留在当前页面。
3. 核对事实与表达，直接编辑结果并点击「保存修改」。每次保存或整套生成都会追加历史版本；展开「历史版本」可以切换查看。
4. 分别复制需要的内容。音频制作指导用于外部音频工具，并应在该工具中选择对应原书来源；书引 AI 不直接生成音频或视频，但可以登记音频成品和剪映导出的最终成片。
5. 封面提示词可分别复制到图片工具，选择相应比例生成无字背景。主副标题用于后期排版。点击「使用这些内容制作封面」进入封面页；有修改时按钮为「保存并制作封面」，保存失败会留在原页。历史版本直达会使用当前选中结果。

读书笔记可点击「导入 TXT / Markdown 笔记」，选择 UTF-8 的 `.txt` 或 `.md` 文件（最大1 MB、10万字）。核对预览后点击「采用并追加到资料」，原有资料保留，并附来源文件名及路径；保存书籍后生效。取消预览不修改资料。此入口只导入笔记文本；PDF/EPUB 等原书文件请使用上面的「选择本地文件」，绑定后作为音频来源，不会自动提取到笔记。

旧结果没有封面字段时会显示为空，原发布文案仍可正常编辑保存；再次点击「一键生成」可得到完整的七项结果，旧版仍保留在历史中。

只想修改部分内容时，点击「按项调整」，勾选要重做的一项或多项，可填写「标题更有悬念但不剧透」等要求，再点击「生成预览」。有未保存修改时，按钮显示「保存并生成预览」；保存失败不会请求模型。调整使用当前选中的历史版本。

生成后逐项比较原内容和候选内容，点击「采用并保存新版本」才追加正式历史，未选中的内容保持原样。「放弃候选结果」保留原内容。调整生成与预览期间原编辑器暂时锁定；采用保存失败时预览保留，可重试。关闭应用前请采用或放弃，预览不保证重启后恢复。音频调整保留主持人甲子，按当前目标时长同步总时长、预计口播字数、开场、五段安排和结尾。改变目标不会改写旧提示词；可重新一键生成，或勾选音频及需要同步的发布文案预览采用。外部工具生成后的实际时长需自行核对。

生成失败、超时或取消会保留已保存版本与当前修改。生成期间编辑的文字也会保留，新生成结果可从历史版本查看。请求最长等待 120 秒，可以点击「取消生成」。

文案和封面配置停止编辑约400毫秒后自动暂存，看到「草稿已自动暂存」后可离页或重启继续，不增加历史版本；正式保存、生成或导出仍按原流程追加历史。离页及正常关闭会等待暂存，失败会提示并留在当前页面。重启自动恢复原来源版本上的草稿；切换历史时仍确认是否放弃。强制终止前尚未写入的输入、未采用的候选预览不保证恢复。书籍表单和发布任务仍需主动保存。

## 4. 音频制作与剪映成片

1. 优先按上方「Gemini Notebook 自动音频」选择来源并启动；也可手动点击「显示浏览器」，在外部工具上传或选择原书来源，粘贴指导并生成。
2. 自动任务成功后音频会出现在列表并复制到本书 `audio/`。手动路径下载音频后返回「音频制作」，点击「导入音频成品」；支持 MP3、M4A、WAV、AAC、FLAC 和 OGG，手动导入只登记原路径。
3. 生成失败、来源处理超时或下载受限时，应用停在明确阶段；按提示人工核对或停止跟进，不重复点击生成。
4. 在剪映导入该音频，生成字幕、添加视频背景并导出最终成片。建议直接导出 MP4；画幅按内容需要选择，应用不限制横竖屏比例。
5. 回到「发布准备」，分别选择制作音频和剪映导出的最终成片。发布检查会读取 MP4/MOV 元数据，确认时长可读取、画面可读取且包含音轨；不限制横竖屏比例，其他格式或损坏的成片需重新导出。
6. 音频不会上传到抖音，也不复制进发布任务包；任务包 manifest 记录音频引用，用于回看这一期采用的制作素材。

## 5. 制作三种比例封面

从书籍页进入「制作封面」，选择纸页或深林模板，填写主标题、副标题与品牌文字，调整字体、字号、颜色和位置。背景可使用纯色或本地 PNG/JPEG/WebP；图片不超过 15 MB、4000 万像素。

如果这本书已生成封面素材，新封面会带入主副标题，确认后保存或导出。已有封面的内容会保留，点击「使用这组主副标题」才替换文字，背景和样式保持不变。上方「本书封面素材」可切换横/竖版提示词并复制，无需配置图片模型。

「用于 AI 背景」会将当前提示词带入画面描述，仍需主动点击「生成 AI 背景」才请求图片服务。切换提示词比例不会替换已经编辑的画面描述。内置服务沿用一张可按三种比例裁切的背景，最终通过本地排版输出三种尺寸；需要横竖两张独立构图时，在外部图片工具中分别使用对应提示词与比例。

选择本地或 AI 背景后，可在主画布拖动背景，也可调整水平位置、垂直位置和1–3倍缩放；「重置背景位置」恢复默认构图。三个比例同时显示预览，核对主体和文字后点击「导出 3 张封面」：

| 文件用途 | 比例 | 像素 |
| --- | --- | --- |
| 横版封面 | 4:3 | 1440×1080 |
| 竖版封面 | 3:4 | 1080×1440 |
| 其他横屏用途 | 16:9 | 1920×1080 |

文件存入该书工作目录的 `covers` 子目录，按「书名-比例-尺寸-v版本.png」命名，例如 `围城-3比4-1080x1440-v3.png`、`围城-16比9-1920x1080-v4.png`；文件版本对应封面历史。比例用「比」连接，书名中的文件名禁用字符会自动处理。每张图追加一个版本，遇到同名文件或目录时继续递增；历史文件不会被覆盖，旧随机文件名保留并可继续读取。文字过多无法放入安全区域时会阻止导出，可缩短文字或减少换行。部分写入失败时，已完成的图片、版本和编辑草稿保留；处理路径或权限问题后重新导出。

在「排版样式」填写「新样式名称」，点击「保存为我的样式」，可在其他书籍直接应用。保存品牌、字体、字号、颜色、蒙层和布局，不保存本书标题、副标题、背景图片、比例或裁切位置；应用后仍可为本书单独调整。删除样式不删除已制作封面。重名时换一个名称。

AI 背景只负责画面，中文仍由程序排版。保存时按图片实际比例和尺寸命名，例如 `围城-1比1-1024x1024-背景-v1.png`，同名背景独立递增版本。生成成功后先检查预览，再导出；生成失败或取消保留原背景与草稿。背景文件移动后可在素材管理中重新定位，也可改用纯色。恢复旧尺寸历史继续编辑时会转换到当前比例，旧历史保持原样。

## 6. 关联音频、成片并生成任务包

1. 进入「发布准备」，展开素材管理，点击「关联素材」选择剪映导出的最终成片。视频只关联路径，不复制到任务包。
2. 新任务文字为空，先在「文案来源版本」明确选择历史文案，或手动填写标题、内容和可选标签。更换来源会先确认替换现有文案；任务保存来源版本及实际文字快照，后续编辑不会改动原历史。选择本书制作音频、最终成片、横版与竖版导出封面，核对实际图片缩略图、版本和尺寸。
3. 核对并勾选标题、两张封面的确认项，点击「生成完整任务包」。音频可用、最终成片含音轨且文件可用、两张封面有效且任务包一致后，任务才为「就绪」。
4. 点击「打开任务包」检查下表中的 8 个文件。目录按书名命名，例如 `publish/三体-发布任务包`，再次生成追加 ` (2)`、` (3)`，旧包保留。

| 文件 | 用途 |
| --- | --- |
| `title.txt` | 发布标题 |
| `description.txt` | 发布内容，保留换行 |
| `tags.txt` | 可选标签，未填写时为空 |
| `video-path.txt` | 剪映导出的最终成片完整路径 |
| `cover-landscape.png` | 横版封面副本 |
| `cover-portrait.png` | 竖版封面副本 |
| `manifest.json` | 任务、素材与文案快照 |
| `README.txt` | 人工上传操作说明 |

保存任务修改、源素材移动或缺失、任务包内容被修改后，需要重新生成。点击「刷新素材与状态」会重查；损坏或与源封面不一致的任务包会退回草稿。任务包生成失败不会删除源视频、音频、已导出封面或旧任务包。

## 7. 辅助发布并记录结果

Windows 可使用「抖音辅助发布」（本轮真实账号及安装验收待补，见 `DOUYIN-FLOW-VERIFICATION.md`）：

1. 选好文案来源、音频、最终成片和两张封面，完成原标题/封面确认项，点击「开始抖音辅助发布」。当前修改会先保存并检查，必要时自动生成任务包；缺项则保留修改并提示。
2. 未登录时在官方窗口扫码。程序等待登录后继续；首次核对官方页账号昵称，点击「使用这个账号继续」。仅昵称不能跨重启证明账号相同，窗口重开后需重新核对。
3. 查看五步进度。程序进入已知上传页并处理当前任务，期间锁定本地编辑和导航；已有视频先要求核对身份，不重传。预览可播放但平台完成信号不能核实时，明确确认上传及处理完成后继续。
4. 从真实选项选择合集或明确不加入。入口无法读取时，可在官方页设置后通过折叠区人工确认；人工结果会标记。只有可验证稳定公开账号 ID 时才提供「记为这个账号的默认选择」，不按昵称存默认。
5. 出现「已准备好，请检查并发布」后，点击「查看抖音并发布」聚焦官方窗口。检查视频、文案、横竖封面、合集、章节、声明和发布设置，亲自点击最终「发布」。上传及填写不会记作已发布。

遇到弹窗、已有草稿或网页人工改动时，会保留内容并就地等待处理，可明确采用网页文案/双封面。已确认且未变的内容恢复时跳过，身份不明时人工核对，不自动覆盖。点击「停止并人工接管」后，等待宿主确认停止才解除本地锁；已开始的网页上传可能仍继续，需在官方页取消。重新开始先核对网页，不自动重传。仍可使用任务包手动完成。

官方窗口的登录态由独立 WebView2 管理，不复制到其他浏览器、任务包或业务备份。macOS/Linux 暂时使用下面的手动流程；Windows 安装验收范围见 `M6-VERIFICATION.md`。

点击「一键复制全部」或单项复制，再打开「抖音创作者中心」。自行登录、选择原视频上传、分别设置两张封面并粘贴文字。检查平台预览后自行完成发布。

只有确认平台实际发布成功后，才回到应用点击「记录发布成功」，填写时间、可选作品链接和备注，再确认保存。上传完成、打开创作者中心和生成任务包都不会自动标记已发布。已发布任务固定保存；准备另一个作品时新建发布任务。

日常可从书架右上角「发布任务」集中处理：默认列出待发布任务，按创建时间排列；可按书名或标题搜索，切换「草稿」补齐缺项，切换「已发布」查看记录或复制作品链接。点击「处理这篇」进入该任务，即使同一本书有更新的任务，也保留原文案来源与素材。不存在的任务需回列表刷新，程序不会改选另一项。

记录结果时，可明确选择下一篇待发布任务，再点击「确认记录并准备下一篇」；只有当前记录写入成功才会开始所选任务。也可仅保存记录，再通过「继续处理下一篇」回列表选择。官方页仍有旧草稿时先处理，不会清空或重传。记录失败保留输入、当前任务和下一篇选择，重试成功前不继续。仅查看列表不会上传或发布；历史安装验收的模拟数据不代表实际平台发布，见 `M7-VERIFICATION.md`。

## 8. 文件移动、备份与恢复

素材显示缺失时，在原素材记录点击「重新定位」，选择移动后的同类型文件。记录 ID 保持，随后刷新发布任务并重新生成任务包。无需删除项目重新创建。

日常迁移优先使用「数据与备份 → 创建完整备份」。默认包含数据库（书籍、历史、自动草稿、个人样式、任务等）、登记的图片/文档、导出封面及当前登记任务包。大视频默认只保留原路径；需要换电脑时勾选「同时包含已关联的原始视频」，并预留相应空间。缺失必需文件时先重新定位，再创建备份。

备份生成 `shuyin-full-backup-…` 目录，内有 `manifest.json`、`database.sqlite3` 和 `files`。**整个目录一起复制或保管，不要只保留 manifest.json。** 未登记文件、无引用的旧任务包和 API Key 不在范围；额外资料需另存，换电脑后在模型设置重新输入密钥。

恢复时点击「选择完整备份恢复」，选择目录内的 `manifest.json`，核对文件数量、体积和未包含视频数，再选择恢复位置并点击「确认完整恢复」。程序校验全部文件，在新建 `shuyin-restored-…` 目录重建素材、封面与任务包引用，再替换数据库；原有文件保留，替换前数据库自动备份并显示路径。未包含的视频保持原路径，失效时重新定位并重新生成任务包。

完整恢复创建的项目目录和任务包也按书名命名，重名追加序号。旧版随机目录不会被直接改名；需要整理时，可先创建完整备份，再按上述流程恢复到新位置。完整备份只包含已登记素材和当前任务包，未登记文件及旧任务包需另行保管。

「数据库备份与恢复」仍支持单独 `.sqlite3`，仅含数据和文件路径。恢复同样需要确认，并先自动保存当前数据库；可用显示的安全备份恢复原记录，原文件仍保留。支持 v2–v13，旧备份在内存升级，源备份不改写。旧待发布任务升级后需补选音频并重新生成任务包。恢复后检查密钥与素材；有正在生成的任务时先取消或等待完成。损坏/缺失文件或校验失败时保留当前数据，重新选择完整有效的备份。

## 9. 常见问题

侧栏底部「关于与更新」可查看当前版本和更新内容。默认启动时自动检查、在后台下载新版本，下载完成后点击「安装并重启」并再次确认。安装前请保存当前工作；进入关于页会沿用原有草稿保存流程。关闭「自动检查并下载更新」后，可随时点击「检查更新 → 下载更新」，仍在应用内完成安装。下载进度不明时显示已下载体积，网络或校验失败后可重试。

Windows 应用内更新适用于 NSIS 安装版；使用 ZIP 时手动下载新版 ZIP 解压替换程序。Linux 使用 AppImage 更新，DEB/RPM 由系统包管理器更新。第一次从没有更新入口的旧版升级，先手动安装含此功能的新版本。更新不删除本地书籍、历史、素材和系统凭据。正式更新源在首次签名版本发布后可用，未配置或网络不通时会明确提示检查失败。

| 提示或现象 | 处理方法 |
| --- | --- |
| 请在桌面应用中操作 | 浏览器预览不提供文件、凭据和数据库操作，启动桌面应用 |
| 认证失败 / 未找到密钥 | 检查服务地址及 API Key，在模型设置重新保存并测试 |
| 限流、网络错误或超时 | 等待后手动重试；已有内容保留，不必反复点击 |
| 模型输出不符合结构 | 当前响应不会入库；检查模型是否支持该任务，必要时换模型后重试 |
| 中文文字放不下 | 缩短标题/副标题、减少手动换行，再检查两个比例 |
| 视频或背景缺失 | 恢复磁盘连接，或在素材记录上重新定位 |
| 应用内网站无法继续 | 点击「查看网站」核对登录和原任务；若 Google 拒绝该浏览环境，保留任务并使用手动导入 |
| 自动音频等待登录 | 在应用打开的网站窗口完成登录/验证码/二次验证；若 Google 拒绝该环境，使用手动音频导入，不向其他工具提供密码 |
| 页面变化或下载受限 | 保持现场人工核对；停止跟进不等于取消 Google 生成，不要立即重发 |
| 发布准备未完成 | 按检查清单补齐文案、素材及人工确认项 |
| 任务包不完整或被修改 | 重新生成完整任务包，旧包保留 |
| 工作目录无法写入 | 检查目录位置、权限和剩余空间；保留现有草稿再重试 |
| 复制失败 | 选中文字后手动复制 |
| 备份不受支持 / 结构错误 | 保留当前数据库，选择本应用生成的受支持备份；高版本数据使用对应新版应用 |

删除书籍会删除其数据库记录和关联历史，源媒体与导出文件保留。需要找回业务记录时使用删除前的数据库备份。

## 10. 三本书试用清单

M5 使用《论语》《西游记》《朝花夕拾》与验收视频，检查每本书的生成、修改、复制、历史切换、双封面和完整任务包。验收视频用于验证路径和流程，不代表该书的正式成片。完整结果、命令和截图位置见 [M5 验证报告](M5-VERIFICATION.md)。

开始制作实际作品时，换成对应成片重新关联并生成任务包，再在平台自行检查上传预览；Windows 应用内网站可自动跟进音频（真实 Google 闭环待验收），剪映成片、试听核对和最终发布仍由你完成；应用负责状态、素材登记、检查与发布准备。
