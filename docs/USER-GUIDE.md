# 书引 AI 使用手册

适用范围：发布文案、音频提示词、封面素材生成、双比例封面与半自动发布工作流。桌面验收以 Windows x64 为准。

## 1. 安装与第一次使用

运行 Windows 安装包，按安装器提示完成安装并启动「书引 AI」。ZIP 版需先解压到固定目录，再运行程序；两种方式均依赖 WebView2，业务数据保存在系统用户目录。

安装升级前先保存正在编辑的内容，并在「模型设置 → 数据备份与应用目录」创建数据库备份。正常关闭应用后运行新安装包，使用同一安装目录。升级后检查已有书籍、历史版本及模型连接；不要通过删除数据库处理升级错误。

正式应用数据库默认位于 `%LOCALAPPDATA%\com.shuyin.desktop\shuyin.sqlite3`。界面的「数据库位置」显示实际路径。更改工作目录只影响以后创建的书籍，不移动已有文件，也不改变数据库位置。可把工作目录设在 D 盘。

隔离验收包名称含 `Verification`，使用独立数据库与凭据，不是正式安装的升级包。

2026-10-24 的本机 M5 交付已将 `D:\MyWork\software\shuyin-ai` 从 0.1.0 升级到本地验收构建 0.5.1，旧数据库记录保留。原程序、原安装包和数据库副本位于仓库 `output/playwright/m5-formal/rollback/`。可交付 EXE、ZIP 和校验清单位于 `output/delivery/m5-windows-0.5.1/`；该目录明确标记为本地构建，未代替 GitHub 正式发布。

## 2. 配置文本模型

进入「模型设置」，选择「文本 · 发布文案」，填写服务名称、可信服务的 API 根地址、模型 ID 和 API Key，勾选启用及默认模型后保存，再点击「测试连接」。

- 根地址通常以 `/v1` 结束；程序追加 `/chat/completions`，不要填写完整聊天接口地址。
- 根地址和模型 ID 以你的服务实际配置为准。服务需支持完整文本响应；连接成功后仍需用一本书检查内容生成。
- API Key 存在操作系统凭据库，普通设置和数据库备份不包含密钥。编辑已有配置时留空会保留原密钥；更换服务地址须重新输入。
- 配置多个文本模型后，可以在文案页选择本次使用的模型。请求可能产生服务费用，失败后由你决定是否重试。

图片模型可选。选择「图片 · AI 封面背景」，保存支持 `/images/generations`、返回 base64 静态 PNG/JPEG/WebP 的服务配置，在封面页主动生成背景。没有图片模型也能完整制作本地封面。

## 3. 添加书籍并准备文案

1. 在「我的书籍」点击「新建项目」，填写书名。建议补充作者、原书资料或本期重点，避免同名书和内容理解偏差。
2. 点击「保存并继续」，再点击「一键生成」。一次生成发布标题、发布内容、音频生成提示词，以及封面主标题、副标题、横版 4:3 与竖版 3:4 的图片提示词。
3. 核对事实与表达，直接编辑结果并点击「保存修改」。每次保存或生成都会追加历史版本；展开「历史版本」可以切换查看。
4. 分别复制需要的内容。音频提示词用于外部音频工具，并应在该工具中选择对应原书来源；书引 AI 不直接生成音频或视频。
5. 封面提示词可分别复制到图片工具，选择相应比例生成无字背景。主副标题用于后期排版。点击「使用这些内容制作封面」进入封面页；有修改时按钮为「保存并制作封面」，保存失败会留在原页。历史版本直达会使用当前选中结果。

旧结果没有封面字段时会显示为空，原发布文案仍可正常编辑保存；再次点击「一键生成」可得到完整的七项结果，旧版仍保留在历史中。

生成失败、超时或取消会保留已保存版本与当前修改。生成期间编辑的文字也会保留，新生成结果可从历史版本查看。请求最长等待 120 秒，可以点击「取消生成」。离开有未保存修改的文案页时，取消离开可继续编辑；请主动保存，未保存内容不承诺崩溃恢复。

## 4. 制作横版和竖版封面

从书籍页进入「制作封面」，选择纸页或深林模板，填写主标题、副标题与品牌文字，调整字体、字号、颜色和位置。背景可使用纯色或本地 PNG/JPEG/WebP；图片不超过 15 MB、4000 万像素。

如果这本书已生成封面素材，新封面会带入主副标题，确认后保存或导出。已有封面的内容会保留，点击「使用这组主副标题」才替换文字，背景和样式保持不变。上方「本书封面素材」可切换横/竖版提示词并复制，无需配置图片模型。

「用于 AI 背景」会将当前提示词带入画面描述，仍需主动点击「生成 AI 背景」才请求图片服务。切换提示词比例不会替换已经编辑的画面描述。内置服务沿用一张可双向裁切的背景，最终通过本地排版输出两种尺寸；需要横竖两张独立构图时，在外部图片工具中分别使用对应提示词与比例。

通过「预览比例」分别检查横版 4:3 和竖版 3:4。点击「导出两张封面」后，程序生成：

| 文件用途 | 比例 | 像素 |
| --- | --- | --- |
| 横版封面 | 4:3 | 1440×1080 |
| 竖版封面 | 3:4 | 1080×1440 |

文件存入该书工作目录的 `covers` 子目录，每张图追加一个版本；历史文件不会被覆盖。文字过多无法放入安全区域时会阻止导出，可缩短文字或减少换行。若第二张写入失败，第一张及其路径保留；处理路径或权限问题后重新导出。

AI 背景只负责画面，中文仍由程序排版。生成成功后先检查预览，再导出；生成失败或取消保留原背景与草稿。背景文件移动后可在素材管理中重新定位，也可改用纯色。恢复旧尺寸历史继续编辑时会转换到当前比例，旧历史保持原样。

## 5. 关联视频与生成任务包

1. 进入「发布准备」，展开素材管理，点击「关联素材」选择本地视频。原视频只关联路径，不复制到任务包。
2. 检查发布标题、内容及可选标签，选择本书的视频、横版与竖版已导出封面。新任务默认带入当前最新文案。
3. 核对并勾选标题、两张封面的确认项，点击「生成完整任务包」。检查清单全部通过后任务为「就绪」。
4. 点击「打开任务包」检查下表中的 8 个文件。每次生成使用新目录，旧包保留。

| 文件 | 用途 |
| --- | --- |
| `title.txt` | 发布标题 |
| `description.txt` | 发布内容，保留换行 |
| `tags.txt` | 可选标签，未填写时为空 |
| `video-path.txt` | 原视频完整路径 |
| `cover-landscape.png` | 横版封面副本 |
| `cover-portrait.png` | 竖版封面副本 |
| `manifest.json` | 任务、素材与文案快照 |
| `README.txt` | 人工上传操作说明 |

保存任务修改、源素材移动或缺失、任务包内容被修改后，需要重新生成。点击「刷新素材与状态」会重查；损坏或与源封面不一致的任务包会退回草稿。任务包生成失败不会删除源视频、已导出封面或旧任务包。

## 6. 手动发布并记录结果

点击「一键复制全部」或单项复制，再打开「抖音创作者中心」。自行登录、选择原视频上传、分别设置两张封面并粘贴文字。检查平台预览后自行完成发布。

只有确认平台实际发布成功后，才回到应用点击「记录发布成功」，填写时间、可选作品链接和备注，再确认保存。上传完成、打开创作者中心和生成任务包都不会自动标记已发布。已发布任务固定保存；准备另一个作品时新建发布任务。

## 7. 文件移动、备份与恢复

素材显示缺失时，在原素材记录点击「重新定位」，选择移动后的同类型文件。记录 ID 保持，随后刷新发布任务并重新生成任务包。无需删除项目重新创建。

完整保管分三部分：

- **数据库备份**：在「数据备份与应用目录」点击「创建备份」，选择保存位置。包含书籍、文案与封面历史、模型配置、素材路径、发布任务和结果记录。
- **文件备份**：另行保存原视频、背景图和项目工作目录（包括 `covers`、`publish`）。数据库备份不包含这些文件，任务包也不包含视频本体。
- **密钥**：由系统凭据库管理，不随数据库备份迁移。换电脑或系统凭据缺失时重新输入密钥。

恢复时选择 `.sqlite3` 备份，核对确认提示后恢复。恢复会替换全部当前业务数据；程序先验证备份，再自动保存恢复前的数据库，完成后显示该安全备份路径。误选了备份时，可使用这个路径恢复回来。

当前支持 v2–v7 数据库备份，旧备份在内存中升级，原文件不改写。恢复后重新检查模型密钥和素材路径；需要继续生成的旧中断任务手动重试。存在正在生成的任务时，先取消或等待完成再恢复。

## 8. 常见问题

| 提示或现象 | 处理方法 |
| --- | --- |
| 请在桌面应用中操作 | 浏览器预览不提供文件、凭据和数据库操作，启动桌面应用 |
| 认证失败 / 未找到密钥 | 检查服务地址及 API Key，在模型设置重新保存并测试 |
| 限流、网络错误或超时 | 等待后手动重试；已有内容保留，不必反复点击 |
| 模型输出不符合结构 | 当前响应不会入库；检查模型是否支持该任务，必要时换模型后重试 |
| 中文文字放不下 | 缩短标题/副标题、减少手动换行，再检查两个比例 |
| 视频或背景缺失 | 恢复磁盘连接，或在素材记录上重新定位 |
| 发布准备未完成 | 按检查清单补齐文案、素材及人工确认项 |
| 任务包不完整或被修改 | 重新生成完整任务包，旧包保留 |
| 工作目录无法写入 | 检查目录位置、权限和剩余空间；保留现有草稿再重试 |
| 复制失败 | 选中文字后手动复制 |
| 备份不受支持 / 结构错误 | 保留当前数据库，选择本应用生成的受支持备份；高版本数据使用对应新版应用 |

删除书籍会删除其数据库记录和关联历史，源媒体与导出文件保留。需要找回业务记录时使用删除前的数据库备份。
