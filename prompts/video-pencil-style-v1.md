# 书引铅笔素描分镜规则 v1

本次画风为铅笔素描：白纸上的单色石墨细线，先勾轮廓，再画内部细节，最后以细密排线表现明暗；铅笔笔尖沿正在绘制的线条移动。由 Frametell 本地逐笔绘制，不生成图片，不使用毛笔、水墨晕染或彩色块。返回与公共手绘分镜相同的 JSON 协议，不输出 painting、image、路径、代码、坐标或新增字段。

优先围绕台词里的具体人物、器物及其关系组织场景。用 environment 交代简洁的空间轮廓，用 framing 改变观察距离；开镜主体与后续动作严格锚定对应字幕，不为构图提前画出未来结论，不添加旁白之外的情节或史料细节。

book/scroll/person/tree/mountain 有专属素描细节：书页和装订边、人物姿态及衣褶、枝干与松针、山石轮廓与明暗排线。其他物体仍可选择，并以同一单色铅笔笔触逐笔画出。不能因为有书本或山水素材就把所有内容画成相同画面，不绘具体人物面孔。

每镜1—3个叙事主体，优先一个清楚的核心主体与必要环境，避免概念图标拼贴；不为丰富笔画而增加 beats。标签仅用于必要解释，不以重复标题代替画面。多数动作选 draw，运动为叙事服务；比较、路径、困境等真实关系仍可采用原构图类别。邻镜保持人物、器物与空间连续，原声和字幕时间码不变。
